# 00 - 快速开始

本教程带你 5 分钟跑通第一个 Fgui 程序：创建窗口、放一个控件、进入主循环。

## 前置条件

- Windows + MinGW-w64（g++）
- SDL2、SDL2_ttf（本仓库已内置在 `dependency/`）
- 一个 `.ttf` 字体文件，本示例使用 `font.ttf`
- Fgui库

## 最小可运行程序

```cpp
#define NOMINMAX
#include "Fgui\Fgui.hpp"

int main(int,char**){
    //初始化SDL
    SDL_Init(SDL_INIT_VIDEO | SDL_INIT_EVENTS);
    TTF_Init();
    SDL_Window* window = SDL_CreateWindow("Minimal Example",SDL_WINDOWPOS_CENTERED,SDL_WINDOWPOS_CENTERED,1000,800,SDL_WINDOW_ALLOW_HIGHDPI);
    SDL_Rect top_relative_rect = {0,0,1000,800};
    SDL_Renderer* renderer = SDL_CreateRenderer(window,-1,SDL_RENDERER_ACCELERATED | SDL_RENDERER_TARGETTEXTURE);
    SDL_SetRenderDrawBlendMode(renderer,SDL_BLENDMODE_BLEND);

    //准备GUI
    FontEx font({"font.ttf"});
    //创建根容器
    std::shared_ptr<ControlBox> cb = std::make_shared<ControlBox>(SDL_Rect{0,0,1000,800});
    //创建一个按钮
    auto button = cb->PushbackControl("hello", std::make_shared<PushButton>("Hello Fgui!",&font,128,SDL_Rect{0,0,0,0}));
    //居中显示
    button->default_rect.x = 500 - button->default_rect.w / 2;
    button->default_rect.y = 400 - button->default_rect.h / 2;
    //设定点击回调
    button->actions.OnClick = [](PushButton *){printf("Hello Fgui!\n");};

    //SDL事件循环必须事项
    SDL_Event eve;
    Timer fps_lim(60);
    bool running = true;

    //SDL事件循环
    while(running){
        //处理SDL事件
        while(SDL_PollEvent(&eve)){
            if(eve.type == SDL_QUIT) running = false;
            if(SDL_GetWindowID(window) == eve.window.windowID) cb->MaintainEvent(&eve,{0,0,1000,800});
        }
        //调用Tick回调
        cb->MaintainTimer({0,0,1000,800});
        //读取脏区域
        SDL_Rect dirty_rect = cb->GetInvaildRect(top_relative_rect);
        //判断是否有脏区域
        if(dirty_rect.w != 0 && dirty_rect.h != 0){
            //脏区域重绘
            SDL_SetRenderDrawColor(renderer,
                cb->GetColorKit().BackgroundColorDarker.r,
                cb->GetColorKit().BackgroundColorDarker.g,
                cb->GetColorKit().BackgroundColorDarker.b, 255);
            SDL_RenderFillRect(renderer, &dirty_rect);
            cb->MaintainRender(renderer, top_relative_rect);
            SDL_RenderPresent(renderer);
        }
        fps_lim.Delay();
    }
    //释放SDL资源
    SDL_DestroyRenderer(renderer);
    SDL_DestroyWindow(window);
    TTF_Quit();
    SDL_Quit();
    return 0;
}
```

## 主循环三件套

每个 Fgui 主循环都要做三件事：

```cpp
// 1. 事件：把 SDL 事件交给根容器（必须传窗口客户区矩形）
cb->MaintainEvent(&eve, {0,0,win_w,win_h});

// 2. 定时器：驱动动画、光标闪烁、控件状态更新（每帧调用）
cb->MaintainTimer({0,0,win_w,win_h});

// 3. 渲染：按脏区只重绘变化部分，效率远高于全量重绘
cb->MaintainRender(renderer, {0,0,win_w,win_h});
//别忘了:
SDL_RenderPresent(renderer);
```

## 添加一个按钮

```cpp
auto btn = std::make_shared<PushButton>("点我",&font,28,SDL_Rect{300,300,0,0});
btn->actions.OnClick = [](PushButton* b){
    printf("按钮被点击了！文本=%s\n", b->GetText().c_str());
};
cb->PushbackControl("button1", btn);
```

控件通过 `actions` 结构体（`std::function` 集合）暴露回调，用法与 WinForms 事件类似。

## 添加一个输入框

```cpp
// flags 支持组合：多行 | 垂直滚动
#define FGUI_INPUTBOX_FLAG_ALLOW_MULTILINES 1
#define FGUI_INPUTBOX_FLAG_VERTICAL_SCROLL  16

auto input = cb->PushbackControl("input1",
    std::make_shared<InputBox>("初始文本",&font,22,
        FGUI_INPUTBOX_FLAG_ALLOW_MULTILINES | FGUI_INPUTBOX_FLAG_VERTICAL_SCROLL,
        SDL_Rect{300,400,400,200}));
// 读取内容
std::string s = input->GetBuffer();
```

## 常见问题

- **编译报 `utf8_to_codepoints_noexcept` 重定义**：说明你没有在 `#include "Fgui\Fgui.hpp"` 之前先 `#include "decode.hpp"`。详见 [常见问题与陷阱](10-常见问题与陷阱.md)。
- **运行后看不到窗口**：请确认把 `SDL2.dll` / `SDL2_ttf.dll` 与字体文件放到了可执行文件同目录。
