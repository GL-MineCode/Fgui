# 00 - 快速开始

本教程带你 5 分钟跑通第一个 Fgui 程序：创建窗口、放一个控件、进入主循环。

## 前置条件

- Windows + MinGW-w64（g++）
- SDL2、SDL2_ttf、SDL2_image（本仓库已内置在 `dependency/`）
- 一个 `.ttf` 字体文件（如 `font.ttf`，测试程序 `test/main.cpp` 使用 `font.ttf`）

> Fgui 的头文件位于 `include/Fgui/`，`Fgui.hpp` 是唯一的入口头文件。

## 最小可运行程序

```cpp
#define NOMINMAX
#include "decode.hpp"               // ⚠️ 必须最先包含（在 Fgui.hpp 之前）
#include "Fgui\Fgui.hpp"            // Fgui 唯一入口头文件

int main(int,char**){
    // 初始化 SDL 视频/事件等子系统（宏来自 SDLWindowStuff.hpp）
    InitAllSDL;

    // 创建窗口（1000x800，允许高DPI）
    SDLWindowStuff* sws = SDLWindowStuff::Create("程序模板",1000,800,SDL_WINDOW_ALLOW_HIGHDPI);
    sws->SetDarkMode(true);
    SDL_Renderer* renderer = sws->CreateRenderer();
    SDL_SetRenderDrawBlendMode(renderer,SDL_BLENDMODE_BLEND);

    // 字体（FontEx 封装了 SDL_ttf，可传入多个字体文件作为回退）
    FontEx font({"font.ttf"});

    // 根容器：一个覆盖整个窗口的 ControlBox
    std::shared_ptr<ControlBox> cb = std::make_shared<ControlBox>(SDL_Rect{0,0,1000,800});

    // 向容器添加控件：PushbackControl(名称, 控件)
    cb->PushbackControl("hello", std::make_shared<StaticText>("Hello Fgui!",&font,32,SDL_Rect{400,350}));

    // 事件循环
    SDL_Event eve;
    EventPlus evp(&eve);
    Timer fps_lim(60);
    while(true){
        while(evp.PollEvent()){
            if(eve.type == SDL_QUIT) return 0;
            // 事件维护：把每个事件交给根容器
            cb->MaintainEvent(&eve,{0,0,1000,800});
        }
        // 定时器维护（动画、光标闪烁等）
        cb->MaintainTimer({0,0,1000,800});
        // 渲染维护（脏区重绘：只重画有变化的区域）
        cb->MaintainRender(renderer,{0,0,1000,800});
        // 提交渲染结果
        SDL_RenderPresent(renderer);
        // 限制帧率
        fps_lim.Wait();
    }
}
```

## 主循环三件套

每个 Fgui 主循环都要做三件事：

```cpp
// 1. 事件：把 SDL 事件交给根容器（必须传窗口客户区矩形）
cb->MaintainEvent(&eve, {0,0,win_w,win_h});

// 2. 定时器：驱动动画、光标闪烁、控件状态更新（每帧调用）
cb->MaintainTimer({0,0,win_w,win_h});

// 3. 渲染：按脏区只重绘变化部分，效率远高于全量重绘
cb->MaintainRender(renderer, {0,0,win_w,win_h});
SDL_RenderPresent(renderer);
```

## 添加一个按钮

```cpp
auto btn = std::make_shared<PushButton>("点我",&font,28,SDL_Rect{300,300,0,0});
btn->actions.OnClick = [](PushButton* b){
    printf("按钮被点击了！文本=%s\n", b->GetText().c_str());
};
cb->PushbackControl("button1", btn);
```

控件通过 `actions` 结构体（`std::function` 集合）暴露回调，用法与 WinForms 事件类似。

## 添加一个输入框

```cpp
// flags 支持组合：多行 | 垂直滚动
#define FGUI_INPUTBOX_FLAG_ALLOW_MULTILINES 1
#define FGUI_INPUTBOX_FLAG_VERTICAL_SCROLL  16

auto input = cb->PushbackControl("input1",
    std::make_shared<InputBox>("初始文本",&font,22,
        FGUI_INPUTBOX_FLAG_ALLOW_MULTILINES | FGUI_INPUTBOX_FLAG_VERTICAL_SCROLL,
        SDL_Rect{300,400,400,200}));
// 读取内容
std::string s = input->GetBuffer();
```

## 常见问题

- **编译报 `utf8_to_codepoints_noexcept` 重定义**：说明你没有在 `#include "Fgui\Fgui.hpp"` 之前先 `#include "decode.hpp"`。详见 [常见问题与陷阱](10-常见问题与陷阱.md)。
- **运行后看不到窗口**：请确认把 `SDL2.dll` / `SDL2_ttf.dll` / `SDL2_image.dll` 与字体文件放到了可执行文件同目录。
