# 04 - 控件参考（上）：基础控件

> 所有控件构造函数的 `rect` 参数均为 `SDL_Rect`（相对父容器的矩形）。
> 若传 `{x,y,0,0}`（尺寸为 0），部分控件会根据文本自动计算宽高。

---

## 1. StaticText —— 静态文本

虽然叫"Static"，但内容可以随时修改。

```cpp
StaticText(const std::string& str, FontEx* _font, int _ptsize, const SDL_Rect& rect = {0,0,0,0});
```

```cpp
auto t = cb->PushbackControl("t1", std::make_shared<StaticText>("你好",&font,28,SDL_Rect{10,20}));

t->SetText("新文本");              // 修改文本（自动重算尺寸）
t->SetFont(&font, 32);            // 改字体/字号
std::string s = t->GetText();     // 读取文本
```

- 文本**居中**绘制（`{0.5f,0.5f}`）。
- 非交互控件（不响应事件）。
- 类型名：`Fgui.StaticText`。

---

## 2. PushButton —— 按钮

```cpp
PushButton(const std::string& str, FontEx* _font, int _ptsize, const SDL_Rect& rect = {0,0,0,0});
```

```cpp
auto b = cb->PushbackControl("b1", std::make_shared<PushButton>("按钮",&font,28,SDL_Rect{100,100}));
b->actions.OnClick = [](PushButton* self){ /* 点击回调 */ };

b->SetText("新标题");
b->GetText();
b->Enable();          // 启用
b->Disable();         // 禁用（点击无效果，文字变灰）
b->IsEnabled();
```

- `actions.OnClick` 在按钮内**松开**时触发。
- 悬停 / 按下有视觉反馈；启用全局动画后颜色平滑过渡。
- 类型名：`Fgui.PushButton`。

---

## 3. LinkText —— 链接文本

带下划线的可点击文本（默认蓝色）。

```cpp
LinkText(const std::string& str, FontEx* _font, int _ptsize, const SDL_Rect& rect = {0,0,0,0});
```

```cpp
auto l = cb->PushbackControl("link", std::make_shared<LinkText>("https://github.com",&font,24,SDL_Rect{100,200}));
l->actions.OnClick = [](LinkText* self){
    ShellExecuteW(NULL, L"open", L"https://github.com", NULL, NULL, SW_SHOWNORMAL);
};
```

- 按下时颜色加深。
- 类型名：`Fgui.PushButton`（源码如此，注意区分）。

---

## 4. CheckBox —— 复选框（三态）

```cpp
CheckBox(const SDL_Rect& rect = {0,0,0,0});
```

```cpp
enum CheckBoxState {
    CHECKBOX_STATE_INDETERMINATE = 2,   // 部分勾选
    CHECKBOX_STATE_CHECKED      = 1,    // 勾选
    CHECKBOX_STATE_UNCHECKED    = 0,    // 不勾选
};
```

```cpp
auto c = cb->PushbackControl("ck", std::make_shared<CheckBox>(SDL_Rect{100,300,50,50}));
c->actions.OnChange = [](CheckBox* self, CheckBox::CheckBoxState state){
    if(state == CheckBox::CHECKBOX_STATE_CHECKED) printf("Checked!\n");
};

c->SetState(CheckBox::CHECKBOX_STATE_INDETERMINATE);  // 编程式设置（不触发回调）
c->SetState(CheckBox::CHECKBOX_STATE_CHECKED, true);  // 带动画
```

- 点击在三态间循环：`勾选 → 不勾选`（从"部分勾选"点击后变为"不勾选"）。
- `SetState` 不触发 `OnChange`。
- 类型名：`Fgui.CheckBox`。

---

## 5. ToggleButton —— 开关

```cpp
ToggleButton(bool default_state, const SDL_Rect& rect = {0,0,0,0});
```

```cpp
auto t = cb->PushbackControl("tg", std::make_shared<ToggleButton>(false, SDL_Rect{100,400,100,50}));
t->actions.OnChange = [](ToggleButton* self, bool on){ printf("开关: %s\n", on?"ON":"OFF"); };

t->SetState(true);              // 编程式设置（不触发回调）
t->SetState(false, true);       // 带动画
```

- 滑块式开关，开/关有位置动画。
- 类型名：`Fgui.ToggleButton`。

---

## 6. RadioButton —— 单选按钮

```cpp
RadioButton(const SDL_Rect& rect = {0,0,0,0});
```

```cpp
auto r1 = cb->PushbackControl("rb1", std::make_shared<RadioButton>(SDL_Rect{100,500,40,40}));
r1->actions.OnChange = [](RadioButton* self){ printf("选中 rb1\n"); };
// 同一 ControlBox 下再放 r2、r3...
```

- **互斥**：点击选中后，通过向 `parent` 广播 `SDL_USEREVENT`（code `SDL_USEREVENT_CODE_RADIOBUTTON_REPEL`），使同容器的其它单选按钮取消选中。
- `SetState(bool, animated=false)` 编程式设置，不触发回调。
- 类型名：`Fgui.RadioButton`。

## 7. PictureBox —— 图片框

```cpp
enum PictureFillingMethod {
    PICTURE_FILLING_METHOD_FIT = 1,      // 等比缩放至刚好放进框内（默认）
    PICTURE_FILLING_METHOD_STRETCH = 2,  // 拉伸填满（变形）
    PICTURE_FILLING_METHOD_FILL = 3,     // 等比缩放填满（可能裁切）
    PICTURE_FILLING_METHOD_TILE = 4,     // 平铺
    PICTURE_FILLING_METHOD_CENTER = 5,   // 原始尺寸居中（过大则裁切）
};

PictureBox(const SDL_Rect& rect = {0,0,0,0},
           SDL_Surface* _image = NULL,
           PictureFillingMethod _filling_method = PICTURE_FILLING_METHOD_FIT);
```

```cpp
SDL_Surface* sur = IMG_Load("gunmu.png");
auto p = cb->PushbackControl("pic", std::make_shared<PictureBox>(SDL_Rect{620,100,200,200}, sur));
SDL_FreeSurface(sur);                 // 内部已复制，可立即释放

p->SetImage(other_sur);               // 换图（内部复制）
p->SetFillingMethod(PictureBox::PICTURE_FILLING_METHOD_STRETCH);
```

- 构造/`SetImage` 内部 `SDL_DuplicateSurface` 复制图片，**不持有**传入 surface 的生命周期。
- 类型名：`Fgui.PictureBox`。

## 8. Slider —— 滑动条

```cpp
Slider(float min = 0.0f, float max = 100.0f, float default_val = 0.0f,
       const SDL_Rect& rect = {0,0,0,0});
```

```cpp
auto s = cb->PushbackControl("sl", std::make_shared<Slider>(0, 100, 50, SDL_Rect{100,600,300,40}));
s->actions.OnBeginDragging = [](Slider* self, float v){};
s->actions.OnDragging      = [](Slider* self, float v){ printf("值: %.1f\n", v); };
s->actions.OnEndDragging   = [](Slider* self, float v){};

s->SetValue(75.0f);                    // 设置数值（自动钳位）
float v = s->GetValue();
s->SetRange(0, 200);                   // 改范围
s->GetMinValue(); s->GetMaxValue();
```

- 拖动滑块或点击轨道即可改变数值；`enable_animation` 下数值平滑过渡（EMA）。
- 类型名：`Fgui.Slider`。
