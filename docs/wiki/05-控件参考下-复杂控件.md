# 05 - 控件参考（下）：复杂控件

## 1. ScrollBarV / ScrollBarH —— 滚动条

垂直 / 水平滚动条，通常由 `ControlBox` 内部使用，也可独立使用。

```cpp
ScrollBarV(int _total_height, int _window_height, const SDL_Rect& rect = {0,0,0,0},
           int _pad_top = 0, int _pad_bottom = 0);
ScrollBarH(int _total_width, int _window_width, const SDL_Rect& rect = {0,0,0,0},
           int _pad_left = 0, int _pad_right = 0);
```

```cpp
auto sb = std::make_shared<ScrollBarV>(1000, 500, SDL_Rect{980,0,20,800});
sb->actions.OnScrolling     = [](int pos,int wh,int th){ /* ... */ return pos; };
sb->actions.OnStopScrolling = [](int pos,int wh,int th){ /* ... */ return pos; };
sb->actions.OnHeightChanged = [](int pos,int wh,int th){ /* ... */ };

sb->SetHeightInfo(2000, 800);      // 更新内容/窗口尺寸
sb->SetScrollPos(300);             // 设置位置
int pos = sb->GetScrollPos();
sb->SetPadding(10, 10);            // 两端额外 padding（可进入负值 / 超出末尾）
bool dragging = sb->IsDragging();  // 是否正在被拖动
```

- `OnScrolling / OnStopScrolling` 返回 `int`（新位置），用 `SetValueIfNotNull` 回写。
- 类型名：`Fgui.ScrollBarV` / `Fgui.ScrollBarH`。

## 2. InputBox —— 输入框（最复杂控件）

支持单行/多行、密码、数字过滤、只读、选区、光标、滚动条、IME 中文输入等。

### 构造与标志

```cpp
InputBox(const std::string& str, FontEx* _font, int _ptsize, int _flags,
         const SDL_Rect& rect = {0,0,0,0});
```

标志位（可组合）：

| 宏 | 值 | 说明 |
| --- | --- | --- |
| `FGUI_INPUTBOX_FLAG_ALLOW_MULTILINES` | 1 | 允许多行（回车换行） |
| `FGUI_INPUTBOX_FLAG_PASSWORD` | 2 | 密码模式（显示 ●） |
| `FGUI_INPUTBOX_FLAG_NUMBER_ONLY` | 4 | 仅数字输入 |
| `FGUI_INPUTBOX_FLAG_READ_ONLY` | 8 | 只读 |
| `FGUI_INPUTBOX_FLAG_VERTICAL_SCROLL` | 16 | 启用垂直滚动条 |
| `FGUI_INPUTBOX_FLAG_HORIZONTAL_SCROLL` | 32 | 启用水平滚动条 |

```cpp
auto input = cb->PushbackControl("input1", std::make_shared<InputBox>(
    "初始文本", &font, 22,
    FGUI_INPUTBOX_FLAG_ALLOW_MULTILINES | FGUI_INPUTBOX_FLAG_VERTICAL_SCROLL,
    SDL_Rect{300,400,400,200}));
```

### 内容读写

```cpp
std::string s = input->GetBuffer();                       // 全部内容（默认 CRLF 换行）
std::string s = input->GetBuffer("\n");                   // 指定换行符
std::string sel = input->GetSelection();                  // 选中文本
input->SetBuffer("新内容");                                // 整体替换（不触发 OnChange）
input->ClearBuffer();                                     // 清空（不触发 OnChange）
input->InsertText("插入");                                // 在光标处插入（触发 OnChange）
input->DeleteText();                                      // 删除选区/前一个字符（触发 OnChange）
```

### 光标与选区

```cpp
input->SelectAll();                       // 全选
input->MoveCursorLeft/Right/Up/Down(shift); // 移动光标
input->SetFocus(true);                    // 聚焦（聚焦后才能接收键盘）
bool f = input->IsFocused();
```

### 其它

```cpp
input->SetFlags(int);                     // 运行时改标志（动态创建/销毁滚动条）
input->GetContentWidth();                 // 内容宽度（缓冲）
input->GetContentHeight();                // 内容高度（缓冲）
input->GetCaretY();                       // 光标在缓冲坐标中的纵坐标
input->GetScrollY();                      // 当前纵向滚动偏移
input->actions.OnChange = [](InputBox* self){ /* 内容变化 */ };
```

### 内置快捷键

| 按键 | 功能 |
| --- | --- |
| ← → ↑ ↓ | 移动光标（+Shift 扩展选区） |
| Backspace | 删除 |
| Ctrl+C / V / X / A | 复制 / 粘贴 / 剪切 / 全选 |
| Enter | 换行（多行模式） |

### 注意

- 单行模式（无滚动条）下 `rect.h == 0` 时自动取字体行高。
- 点击输入框内部会自动 `SDL_StartTextInput` 启用 IME。
- 类型名：`Fgui.InputBox`。

## 3. ComboBox —— 下拉列表框

采用自研 `PopupWindow`（Win32 子窗口 + 软件渲染器）实现的下拉弹窗，支持悬停高亮、滚轮滚动、可拖拽滚动条、自动上下翻转、Escape/失焦/点击外部关闭。

```cpp
struct ComboItem {
    std::string ui_string;   // 显示文本
    int id;                  // 值（勿用 0xFFFFFFFF，那是"未选中"保留值）
    int priority;            // 排序优先级，越大越靠前（默认 0）
};

ComboBox(const std::string& _default_text,
         const std::vector<ComboItem>& _items,
         int _id_item_chosen,          // 默认选中 id；(int)0xFFFFFFFF = 不选
         FontEx* _font, int _ptsize,
         const SDL_Rect& rect = {0,0,0,0});
```

```cpp
auto combo = cb->PushbackControl("combo", std::make_shared<ComboBox>(
    "-", std::vector<ComboBox::ComboItem>{
        {"选项A", 1, 100},
        {"选项B", 2, 100},
        {"选项C", 3, 50},
    }, 1, &font, 28, SDL_Rect{510,10,0,0}));

combo->actions.OnChange = [](ComboBox* self, const ComboBox::ComboItem& item){
    printf("选中 id=%d text=%s\n", item.id, item.ui_string.c_str());
};
```

### API

```cpp
combo->GetSelectedItem();          // ComboItem（未选中返回 id=0xFFFFFFFF）
combo->GetSelectedID();            // int，0xFFFFFFFF 表示未选中
combo->SelectItem(2);              // 编程式选中（不触发 OnChange）
combo->SetItems(vec, chosen_id);   // 重新设置条目
combo->SetFont(&font, 30);
combo->GetItemCount();             // 条目数
combo->GetItem(i);                 // 取第 i 个条目
combo->IsDropdownOpen();           // 下拉是否打开
combo->Enable(); combo->Disable(); combo->IsEnabled();
```

- 下拉框**不显示当前已选中项**（选中项只在本体显示）。
- 类型名：`Fgui.ComboBox`。

## 4. ProgressBar —— 进度条（三态）

```cpp
enum ProgressBarState {
    PROGRESSBAR_STATE_PAUSED     = 0,  // 暂停：显示当前进度但不再前进（填充变暗）
    PROGRESSBAR_STATE_PROCESSING = 1,  // 处理中：进度未知，往复动画
    PROGRESSBAR_STATE_NORMAL     = 2,  // 正常：显示确定进度
};

ProgressBar(float min, float max, float default_val,
            FontEx* _font = nullptr, int _ptsize = 0,
            ProgressBarState _state = PROGRESSBAR_STATE_NORMAL,
            const SDL_Rect& rect = {0,0,0,0});
```

```cpp
auto pb = cb->PushbackControl("pb", std::make_shared<ProgressBar>(0, 100, 75, &font, 22));
pb->actions.OnValueChanged = [](ProgressBar* self, float v){};

pb->SetValue(80);                  // 设置值（自动钳位）
pb->SetValue(80, true);            // 平滑过渡（需开启动画）
pb->GetValue();
pb->GetProgress();                 // 0~1
pb->SetProgress(0.5f);
pb->SetRange(0, 200);
pb->SetState(ProgressBar::PROGRESSBAR_STATE_PROCESSING);  // 切到"处理中"
pb->IsProcessing();
pb->SetAnimPeriod(1200);           // 动画周期 ms
pb->SetAnimBlockRatio(0.3f);       // 动画块占比 0.05~0.6
pb->SetShowText(true, &font, 22);  // 居中显示百分比
pb->IsShowText();
```

- `_font` 非空时默认居中显示百分比文本（`show_text`）。
- `NORMAL` 态确定进度 + EMA 平滑；`PROCESSING` 态推挽式往复动画块（不显示百分比）；`PAUSED` 态填充/文本变暗。
- 类型名：`Fgui.ProgressBar`。

## 5. TabControl —— 选项卡

多标签页容器，支持标签条四方向、关闭按钮、拖动重排。

```cpp
#define TAB_FLAG_NONE          0
#define TAB_FLAG_CLOSE_BUTTON  1     // 显示关闭按钮
#define TAB_FLAG_ALLOW_REARRANGE 2   // 允许拖动重排
#define TAB_FLAG_POS_TOP       0x00
#define TAB_FLAG_POS_BOTTOM    0x10
#define TAB_FLAG_POS_LEFT      0x20
#define TAB_FLAG_POS_RIGHT     0x30
#define TAB_FLAG_POS_MASK      0x30

TabControl(int _flags = TAB_FLAG_NONE, FontEx* _font = nullptr, int _ptsize = 0,
           const SDL_Rect& rect = SDL_Rect{0,0,0,0});
```

```cpp
class TabItem {
public:
    std::string name;                    // 标签名
    std::string id;                      // 标签 ID（唯一）
    std::shared_ptr<ControlBox> content; // 标签内容（一个容器）
};
```

```cpp
auto tabs = cb->PushbackControl("tabs", std::make_shared<TabControl>(
    TAB_FLAG_CLOSE_BUTTON | TAB_FLAG_ALLOW_REARRANGE | TAB_FLAG_POS_TOP,
    &font, 18, SDL_Rect{0,60,1000,700}));

auto page = std::make_shared<ControlBox>();
page->PushbackControl("txt", std::make_shared<StaticText>("页面1",&font,20,SDL_Rect{10,10}));
TabControl::TabItem item{"文档1", "doc1", page};
tabs->PushbackTab(item);

tabs->ActivateTab("doc1");               // 激活
TabControl::TabItem* active = tabs->GetActiveTab();  // 当前激活页（无则 nullptr）
```

### 回调

```cpp
tabs->actions.OnTabClose    = [](TabControl::TabItem& tab)->bool{ return true; }; // 返回 false 阻止关闭
tabs->actions.OnTabActive   = [](TabControl::TabItem& tab)->bool{ return true; }; // 返回 false 阻止激活
tabs->actions.OnTabRearrange= [](TabControl::TabItem& tab){ /* 拖动重排后 */ };
```

### 其它 API

```cpp
tabs->PushbackTab(item);  tabs->PushfrontTab(item);   // 返回 TabItem&（内部存储）
tabs->EraseTab("id");                                  // 移除（不触发 OnTabClose）
tabs->TopTab("id");  tabs->BottomTab("id");            // 置前/置后（不激活）
tabs->GetTabIndex("id");  tabs->GetTabCount();  tabs->ClearTabs();
tabs->GetTab("id");                                    // TabItem&
tabs->SetFont(&font, 18);
tabs->SetStripPosition(TAB_FLAG_POS_LEFT);             // 改条位置
tabs->SetAllowRearrange(true);  tabs->IsAllowRearrange();
```

- 激活页内容区 `default_rect` 由 `TabControl` 自动同步为内容区尺寸。
- 事件/定时器会转发给激活页；滚轮消费也会逐层上报。
- 类型名：`Fgui.TabControl`。

## 6. QRCodeBox —— 二维码控件（可选模块）

需在包含 `Fgui.hpp` 前定义 `ENABLE_QRCODE_MODULE`，并链接 `qrcodegen.cpp`。

```cpp
QRCodeBox(const std::string& text = "",
          qrcodegen::QrCode::Ecc _ecc = qrcodegen::QrCode::Ecc::MEDIUM,
          int _module_size = 4, int _padding = 2,
          const SDL_Rect& rect = {0,0,0,0});
```

```cpp
auto qr = cb->PushbackControl("qr", std::make_shared<QRCodeBox>("https://github.com",
    qrcodegen::QrCode::Ecc::HIGH, 4, 2, SDL_Rect{100,100,256,256}));

qr->SetContent("新的内容");                 // 重新生成
const std::string& c = qr->GetContent();
qr->SetModuleSize(6);
qr->SetECC(qrcodegen::QrCode::Ecc::LOW);
qr->SetPadding(3);
qr->SetQRColor({0,0,0,255}, {255,255,255,255});  // 前景/背景色
```

- 内部用 `PictureBox` 显示生成的二维码表面。
- 生成失败（如内容过长）时自动清空图像。
- 类型名：`Fgui.QRCodeBox`。
