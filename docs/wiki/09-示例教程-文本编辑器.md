# 09 - 示例教程：文本编辑器

源码：`example/001_TextEditor.cpp`。这是 Fgui 目前最完整的实战示例，演示了 `TabControl`、`InputBox`、`ComboBox`、自定义控件、状态栏、撤销/重做等综合用法。

## 功能一览

- 多标签页编辑（每标签一个 `InputBox`，支持中文 IME、选区、Ctrl+C/X/V/A）
- 撤销 / 重做（基于 `InputBox::OnChange` 回调做状态快照，每标签独立）
- 状态栏（文件名 / 字符数 / 行数 / 修改标志）+ 窗口标题 / 标签页标题 `*` 指示
- 关闭未保存标签、退出前弹「保存 / 不保存 / 取消」确认框
- 快捷键：`Ctrl+N/O/S/W`、`Ctrl+Shift+S`、`Ctrl+Z/Y`、`Tab` 插入制表符

## 架构总览

```
主窗口 (SDL_WindowIM::WindowIM)
 └── 根 ControlBox g_cb
      ├── 菜单栏：3 个 ComboBox 模拟（字号 24，铺满顶栏）
      ├── TabControl g_tabs   ← 多标签容器
      │     └── 每标签 DocState：
      │           page (ControlBox)
      │             ├── LineNumberGutter (自定义控件，左侧行号栏)
      │             └── InputBox editor (编辑区)
      └── 状态栏 StaticText（贴底钳制）
```

## 关键代码片段

### 1. 数据模型

```cpp
struct DocState {
    std::string path;
    bool modified = false;
    std::string saved_buffer;
    std::string newline = "\r\n";
    // 撤销/重做栈
    std::deque<std::string> undo_stack, redo_stack;
    std::shared_ptr<ControlBox> page;
    std::shared_ptr<InputBox> editor;
    std::shared_ptr<LineNumberGutter> gutter;
};

std::map<std::string, DocState> g_docs;   // 以 tab_id 为键
```

### 2. 创建标签页

```cpp
void NewTab(const std::string& id, const std::string& title, const std::string& content){
    auto page = std::make_shared<ControlBox>();   // 每页一个容器
    DocState d;
    d.page = page;
    d.editor = std::make_shared<InputBox>(content, &g_font, 22,
        FGUI_INPUTBOX_FLAG_ALLOW_MULTILINES | FGUI_INPUTBOX_FLAG_VERTICAL_SCROLL,
        SDL_Rect{0,0,0,0});                        // 尺寸由 SyncTabEditorSizes 每帧设置
    d.gutter = std::make_shared<LineNumberGutter>(d.editor.get(), &g_font, 22, SDL_Rect{0,0,g_gutter_w,0});

    page->PushbackControl("gutter", d.gutter);
    page->PushbackControl("editor", d.editor);
    d.editor->actions.OnChange = [&d](InputBox*){ /* 快照 + 状态栏刷新 */ };

    g_docs[id] = d;
    g_tabs->PushbackTab(TabControl::TabItem{title, id, page});
    g_tabs->ActivateTab(id);
}
```

### 3. 每帧同步编辑区尺寸

```cpp
void SyncTabEditorSizes(){
    auto* tab = g_tabs->GetActiveTab();
    if(!tab) return;
    auto& d = g_docs[tab->id];
    // 编辑区跟随 page（已由 TabControl 同步为内容区尺寸）
    SDL_Rect pr = d.page->default_rect;
    d.gutter->default_rect = {0, 0, g_gutter_w, pr.h};
    d.editor->default_rect = {g_gutter_w, 0, pr.w - g_gutter_w, pr.h};
}
```

### 4. 撤销 / 重做

基于 `OnChange` 快照：

```cpp
// 每次内容变化时把旧内容压入 undo 栈
d.editor->actions.OnChange = [&d](InputBox*){
    d.undo_stack.push_back(d.saved_buffer);
    if(d.undo_stack.size() > 100) d.undo_stack.pop_front();
    d.redo_stack.clear();
    d.modified = (d.editor->GetBuffer() != d.saved_buffer);
};

void DoUndo(){
    auto& d = ActiveDoc();
    if(d.undo_stack.empty()) return;
    d.redo_stack.push_back(d.editor->GetBuffer());
    d.editor->SetBuffer(d.undo_stack.back());
    d.undo_stack.pop_back();
}
```

### 5. 菜单栏（ComboBox 模拟）

// 菜单栏 = 3 个 ComboBox，字号 24，宽度自然自适应、高度铺满顶栏
auto MakeMenu = [&](const char* title, std::vector<ComboBox::ComboItem> items){

> `ComboBox` 无选中项时显示 `default_text`，被用来当作菜单按钮；`OnChange` 里执行对应操作后 `SelectItem(0xFFFFFFFF)` 复位。

            int lh = GetLineHeight();
            // 对可见行号逐行绘制（居中）
            /* ... */
        }
    }
    void ActionOnTimer(const SDL_Rect&) override {
        // 检测编辑器滚动/视口变化 → 自重绘
        int cam = editor ? editor->GetScrollY() : 0;

### 7. 关闭 / 退出确认

```cpp
// 标签关闭按钮 → OnTabClose 回调
g_tabs->actions.OnTabClose = [](TabControl::TabItem& tab)->bool{
    auto& d = g_docs[tab.id];
    if(d.modified){
        // 弹「保存/不保存/取消」对话框，返回 false 可阻止关闭
        int r = MessageBox(...);
        if(r == IDCANCEL) return false;
        if(r == IDYES) SaveDoc(d);
    }
    g_docs.erase(tab.id);           // 清理数据
    return true;
};
```

## 从示例学到的模式

1. **多标签编辑器**：`std::map<string, DocState>` + `TabControl`，激活页数据用 `GetActiveTab()` 取。
2. **无排版引擎的布局**：在 `LayoutControls` / `SyncTabEditorSizes` 里手动计算每个控件矩形。
3. **自定义控件集成**：行号栏通过轮询 `editor->GetScrollY()` 保持同步。
4. **`OnChange` 与撤销栈**：内容变更回调只由用户编辑触发（`SetBuffer` 不会触发），适合做快照。
