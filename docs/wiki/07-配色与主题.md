# 07 - 配色与主题

## Fgui_ColorKit

所有控件通过 `color_kit`（`Fgui_ColorKit`）取色绘制。它有 8 个字段：

```cpp
struct Fgui_ColorKit {
    SDL_Color ForegroundColor;          // 前景色（主色/强调色）
    SDL_Color BackgroundColor;          // 背景色
    SDL_Color ForegroundColorDarker;    // 更深的前景色（按下/深色填充）
    SDL_Color BackgroundColorDarker;    // 更深的背景色（标签条等）
    SDL_Color ForegroundColorLighter;   // 更亮的前景色（悬停/高亮）
    SDL_Color BackgroundColorLighter;   // 更亮的背景色
    SDL_Color BorderColor;              // 边框色
    SDL_Color TextColor;                // 文本色
};
```

## 内置配色预设

`ColorKitPresets` 命名空间提供了 11 套预设：

| 名称 | 说明 |
| --- | --- |
| `ColorKitPresets::Default` | 默认 = Dark |
| `ColorKitPresets::Dark` | 纯深色主题 |
| `ColorKitPresets::Light` | 浅色主题 |
| `ColorKitPresets::Blue` | 蓝色主题 |
| `ColorKitPresets::Green` | 绿色主题 |
| `ColorKitPresets::Red` | 红色主题 |
| `ColorKitPresets::Orange` | 橙色主题 |
| `ColorKitPresets::Purple` | 紫色主题 |
| `ColorKitPresets::Terminal` | 终端风格（黑底绿字） |
| `ColorKitPresets::Ocean` | 海洋主题 |
| `ColorKitPresets::Sunset` | 日落主题 |

`DefaultColorKit` 宏默认展开为 `ColorKitPresets::Default`（即 Dark）。控件默认配色即取它。

## 指定全局默认配色

在包含 `Fgui.hpp` **之前**定义 `DefaultColorKit` 宏：

```cpp
#define DefaultColorKit ColorKitPresets::Ocean
#include "decode.hpp"
#include "Fgui\Fgui.hpp"
```

（示例 `001_TextEditor.cpp` 即用此法把默认主题设为 Ocean。）

## 运行时换肤

对根容器调用 `ActionOnColorKitChange`，会**递归**把新配色下发给所有子控件（含滚动条）：

```cpp
cb->ActionOnColorKitChange(ColorKitPresets::Blue);   // 一键换肤
```

在 `test/main.cpp` 中，通过一个 `ComboBox` 选择主题，`OnChange` 里调用此方法即可实时切换：

```cpp
ctl->actions.OnChange = [cb](ComboBox*, const ComboBox::ComboItem& item){
    Fgui_ColorKit ck = ColorKitPresets::Default;
    switch(item.id){ /* ... 映射到各预设 ... */ }
    cb->ActionOnColorKitChange(ck);
};
```

## 自定义配色

直接构造一个 `Fgui_ColorKit` 结构体：

```cpp
Fgui_ColorKit myTheme = {
    {59,130,246,255},   // ForegroundColor
    {30,41,59,255},     // BackgroundColor
    {37,99,235,255},    // ForegroundColorDarker
    {15,23,42,255},     // BackgroundColorDarker
    {96,165,250,255},   // ForegroundColorLighter
    {51,65,85,255},     // BackgroundColorLighter
    {0,0,0,255},        // BorderColor
    {255,255,255,255}   // TextColor
};
cb->ActionOnColorKitChange(myTheme);
```

## 获取当前配色

```cpp
const Fgui_ColorKit& ck = ctrl->GetColorKit();   // 控件当前配色
```

## 动画

```cpp
void Fgui_ConfigControlAnimation(bool enable);   // 全局控件动画开关
```

开启动画后，按钮悬停/按下、开关切换、滚动条滚动等会带有平滑过渡（EMA 颜色插值）。代价是更多的定时器重绘。
