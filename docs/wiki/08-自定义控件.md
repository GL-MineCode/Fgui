# 08 - 自定义控件

Fgui 的自定义控件很简单：继承 `Fgui_Control`，实现四个纯虚函数，再重载需要的虚函数即可。

## 最小自定义控件

```cpp
class MyControl : public Fgui_Control {
public:
    // 构造：初始化矩形并请求重绘
    MyControl(const SDL_Rect& rect = {0,0,0,0}){
        default_rect = rect;
        this->InvalidateRect();
    }

    // 1. 绘制：这里拿到 renderer，画控件外观
    void ActionOnPaint(SDL_Renderer* renderer, const SDL_Rect& dirty_region,
                       const SDL_Rect& relative_rect) override {
        // 注意：绘制时 relative_rect 已是屏幕绝对位置（含滚动偏移）
        SDL_Rect draw_area = default_rect;
        draw_area.x = relative_rect.x;
        draw_area.y = relative_rect.y;

        SDL_SetRenderDrawColor(renderer, ColorArg(color_kit.BackgroundColor));
        SDL_RenderFillRect(renderer, &draw_area);
        SDL_SetRenderDrawColor(renderer, ColorArg(color_kit.BorderColor));
        SDL_RenderDrawRect(renderer, &draw_area);
    }

    // 2. 事件：处理鼠标/键盘
    void ActionOnEvent(const SDL_Event* event, const SDL_Rect& relative_rect) override {
        if(event->type == SDL_MOUSEBUTTONDOWN && event->button.button == SDL_BUTTON_LEFT){
            SDL_Point pt = RelativizePoint({event->button.x, event->button.y}, relative_rect);
            if(isPointInsideRect(pt, default_rect)){
                // 注意：事件里算屏幕矩形要加 default_rect.xy（与绘制不同！）
                printf("MyControl 被点击\n");
            }
        }
    }

    // 3. 定时器：每帧或按 timer_time 调用（动画等）
    void ActionOnTimer(const SDL_Rect& relative_rect) override {
    }

    // 4. 类型名："包名.控件名" 规范
    std::string ActionOnGetTypeName() const override {
        return "Fgui.MyControl";
    }
};
```

## 关键虚函数速查

| 虚函数 | 是否必须 | 说明 |
| --- | --- | --- |
| `ActionOnPaint(renderer, dirty, relative_rect)` | ✅ | 绘制外观 |
| `ActionOnEvent(event, relative_rect)` | ✅ | 处理事件 |
| `ActionOnTimer(relative_rect)` | ✅ | 定时器/动画 |
| `ActionOnGetTypeName()` | ✅ | 返回类型名 |
| `ActionOnColorKitChange(ck)` | 可选 | 响应换肤（默认仅改自身颜色 + 重绘） |
| `InvalidateRect()` / `InvalidateRect(rect)` | 可选 | 重载以自定义脏区外扩 |
| `SetVisibility(bool)` | 继承 | 可见性控制 |

## 使用自定义控件

```cpp
auto mc = cb->PushbackControl("my1", std::make_shared<MyControl>(SDL_Rect{100,100,200,80}));
```

## 常见模式

### 1. 自定义脏区外扩

圆角矩形/带阴影控件需要比 `default_rect` 更宽的脏区：

```cpp
void InvalidateRect() override{
    this->InvalidateRect(SDL_Rect{-10,0,default_rect.w+20,default_rect.h});
}
void InvalidateRect(const SDL_Rect& rect) override{
    dirty_region = ExtendRect(dirty_region, rect);
}
```

（`Slider`、`ProgressBar` 就是这样做的。）

### 2. 定时器做动画

```cpp
class BlinkDot : public Fgui_Control {
    uint64_t t0;
public:
    BlinkDot(const SDL_Rect& r){ default_rect = r; timer_time = 100; t0 = SDL_GetTicks64(); this->InvalidateRect(); }
    void ActionOnTimer(const SDL_Rect&) override { this->InvalidateRect(); }  // 每 100ms 重绘
    void ActionOnPaint(SDL_Renderer* r, const SDL_Rect&, const SDL_Rect& rel) override {
        bool on = ((SDL_GetTicks64() - t0) / 500) % 2 == 0;
        SDL_SetRenderDrawColor(r, on ? 255 : 80, 80, 80, 255);
        SDL_Rect d = {rel.x, rel.y, default_rect.w, default_rect.h};
        SDL_RenderFillRect(r, &d);
    }
    void ActionOnEvent(const SDL_Event*, const SDL_Rect&) override {}
    std::string ActionOnGetTypeName() const override { return "Fgui.BlinkDot"; }
};
```

> 设置 `timer_time`（毫秒）可让 `ActionOnTimer` 分频调用，`0` = 每帧。

### 3. 交互控件 + 回调

```cpp
class ToggleSwitch : public Fgui_Control {
    bool state = false;
public:
    struct Actions{ std::function<void(ToggleSwitch*,bool)> OnChange; } actions;

    ToggleSwitch(bool def, const SDL_Rect& r){ state = def; default_rect = r; this->InvalidateRect(); }

    void ActionOnEvent(const SDL_Event* e, const SDL_Rect& rel) override {
        if(e->type == SDL_MOUSEBUTTONUP && e->button.button == SDL_BUTTON_LEFT){
            SDL_Point pt = RelativizePoint({e->button.x, e->button.y}, rel);
            if(isPointInsideRect(pt, default_rect)){
                state = !state;
                CallIfNotNull(actions.OnChange, this, state);
                this->InvalidateRect();
            }
        }
    }
    /* ActionOnPaint / ActionOnTimer / ActionOnGetTypeName ... */
};
```

### 4. 容器型自定义控件

若你的控件要**管理子控件**（类似 `ControlBox`/`TabControl`），必须在 `ActionOnTimer` 中调用子容器/子控件的 `MaintainTimer`，否则子树脏区与定时逻辑会断（表现为"内容区永不重绘 / 点了没反应"）。

```cpp
void ActionOnTimer(const SDL_Rect& rel) override {
    // 必须传子容器"局部坐标 {0,0,w,h}"，绝不能传屏幕坐标！
    child_cbox->MaintainTimer({0,0,child_cbox->default_rect.w, child_cbox->default_rect.h});
    SDL_Rect cd = child_cbox->GetRelativeInvaildRect();
    if(cd.w > 0 && cd.h > 0) this->InvalidateRect(cd);   // 汇总子控件脏区
}
```
