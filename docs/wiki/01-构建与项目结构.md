# 01 - 构建与项目结构

## 目录结构

```
fast_gui2/
├── CMakeLists.txt          # 主构建脚本
├── CMakePresets.json       # CMake 预设（debug / release / debug-examples / release-examples）
├── makefile                # 旧版 Makefile（已废弃，仅供参考）
├── README.md
├── include/
│   └── Fgui/               # ★ Fgui 库本体（头文件库，无 .cpp）
│       ├── Fgui.hpp            # 唯一入口头文件
│       ├── Fgui_includes.hpp   # 集中包含所有依赖（SDL、FontEx、decode 等）
│       ├── Fgui_math.hpp       # 数学工具（HSV/RGB 转换、质心等）
│       ├── Fgui_defs.hpp       # 宏定义（ColorArg 等）
│       ├── Fgui_graphic.hpp    # 图形绘制函数 + TooltipWindow/PopupWindow
│       ├── Fgui_controls.hpp   # ★ 全部控件类定义
│       └── QR-Code-generator/  # 二维码生成库（可选模块）
├── test/
│   └── main.cpp            # 测试程序 -> bin/main.exe
├── example/
│   └── 001_TextEditor.cpp  # 文本编辑器示例 -> example/example_001_TextEditor.exe
├── dependency/             # SDL2 3 件套
│   ├── SDL2-2.32.10/
│   ├── SDL2_ttf-2.24.0/
│   └── SDL2_image-2.8.12/
├── diag/                   # 独立诊断程序（不参与主构建）
├── res/                    # 资源（图片、字体等）
└── docs/wiki/              # 本 Wiki
```

## 依赖

Fgui 只依赖 SDL2 三件套：

| 库 | 版本（仓库内置） | 用途 |
| --- | --- | --- |
| SDL2 | 2.32.10 | 窗口 / 渲染 / 事件 |
| SDL2_ttf | 2.24.0 | 字体渲染（经 `FontEx` 封装） |
| SDL2_image | 2.8.12 | 图片加载（`PictureBox`、`IMG_Load`） |

> 附加依赖（非 SDL 官方）：
> - 工具头文件（`FontEx.hpp`、`decode.hpp`、`SDLWindowStuff.hpp`、`SmoothCpp.hpp` 等）与 GL_Commdlg 对话框库。构建时 CMake 会**优先使用本机开发路径**（`D:/AppInstallers/RecentlyC++Programs` 与 `D:/Desktop/Git/GL_Commdlg/include`），**若不存在则自动回退到仓库内的 `otherlibs/` 目录**。详见下文「otherlibs 目录」。
> - Win32 API（`windows.h`、`commdlg.h` 等）—— 用于弹窗、文件对话框等 Windows 特性。

## otherlibs 目录

`otherlibs/` 是本仓库用来存放一些工具头文件的地方

**① Fgui 库本体必需（任何程序都要编译它）**

| 文件 | 说明 |
| --- | --- |
| `SmoothCpp.hpp` | 数值平滑（EMA/颜色插值） |
| `SDLWindowStuff.hpp` | SDL 窗口封装（创建渲染器等） |
| `AdvancedSDLWindow.hpp` | `SDLWindowStuff` 依赖（Win32 窗口操作） |
| `GL_DWMoperations.hpp` | `SDLWindowStuff` 依赖（DWM 毛玻璃/圆角等） |
| `Times.hpp` | 帧率限制 `Timer` |
| `DebugText.hpp` | 调试文本绘制 |
| `decode.hpp` | UTF-8/GBK 编解码（**必须先于 Fgui.hpp 包含**） |
| `FontEx.hpp` | SDL_ttf 封装（字体/布局） |

**② 测试程序 `test/main.cpp`（`FGUI_BUILD_TEST=ON`）额外需要**

| 文件 | 说明 |
| --- | --- |
| `SDL_EventPlus.hpp` | SDL 事件增强封装 |
| `StopWatch.hpp` | 计时器 |
| `TimeCounter.h` | `StopWatch` 依赖（高精度计时） |

**③ 示例程序 `example/001_TextEditor.cpp`（`FGUI_BUILD_EXAMPLES=ON`）额外需要**

| 文件 | 说明 |
| --- | --- |
| `GL_Commdlg.hpp` | 文件打开/保存等系统对话框封装 |
| `GL_Commdlg_Native.hpp` | `GL_Commdlg` 依赖 |
| `GL_Commdlg_Extended.hpp` | `GL_Commdlg` 依赖 |
| `UTF8toWide.hpp` | 上述两者依赖（宽字符转换） |

## CMake 预设

```bash
# 4 个预设：
#   debug            Debug，仅测试程序 main.exe
#   release          Release，仅测试程序 main.exe
#   debug-examples   Debug，测试程序 + 示例
#   release-examples Release，测试程序 + 示例
```

构建测试程序（Debug）：

```bash
cmake --preset debug
cmake --build build/debug --target fast_gui2 -j
```

构建示例（含测试程序）：

```bash
cmake --preset debug-examples
cmake --build build/debug-examples --target examples -j
```

## CMake 选项

| 选项 | 默认 | 说明 |
| --- | --- | --- |
| `FGUI_BUILD_TEST` | ON | 编译 `test/main.cpp` -> `bin/main.exe` |
| `FGUI_BUILD_EXAMPLES` | OFF | 编译 `example/*.cpp` -> `example/` 下 |

用法：`cmake -DFGUI_BUILD_TEST=OFF -DFGUI_BUILD_EXAMPLES=ON ...`

## 输出位置与运行

- 测试程序输出到 `bin/main.exe`
- 示例输出到 `example/example_001_TextEditor.exe`
- 编译器标志：`-fexec-charset=UTF-8 -static-libstdc++ -static-libgcc -Wno-narrowing -Wno-conversion-null`
- C++ 标准：**C++20**

运行前请把以下文件复制到可执行文件所在目录：

```
SDL2.dll
SDL2_ttf.dll
SDL2_image.dll
font.ttf            （以及用到的其它资源）
```

## ⚠️ 包含顺序（重要）

任何源文件都必须遵守：

```cpp
#include "decode.hpp"        // 第一步：先包含 decode.hpp
#include "Fgui\Fgui.hpp"     // 第二步：再包含 Fgui.hpp
```

原因：`Fgui_includes.hpp` 内部先包含 `DebugText.hpp` 再包含 `decode.hpp`，若 `decode.hpp` 未先被包含，`DebugText.hpp` 中的 `utf8_to_codepoints_noexcept` 会与 `decode.hpp` 重定义，导致编译错误：

```
redefinition of 'std::vector<unsigned int> utf8_to_codepoints_noexcept(...)'
```

> 此外若需启用二维码模块，须在包含 `Fgui.hpp` **之前**定义 `ENABLE_QRCODE_MODULE`：
> ```cpp
> #define ENABLE_QRCODE_MODULE
> #include "decode.hpp"
> #include "Fgui\Fgui.hpp"
> ```

## 添加一个示例

在 `example/` 下新建 `002_XXX.cpp`，再次运行 `cmake --preset debug-examples` 并构建 `examples` 目标即可自动纳入编译（`file(GLOB ...)` 自动收集）。
